## алгоритм выполнения программы

1. Пользователь запускает утилиту для копирования файлов
    1. Возможна передача аргументами коллекции путей исходников и целевой путь
    2. Если аргументы переданы не были, то необходимо попробовать прочитать файл `.json` с настройками
    3. Если его нет попросить полькователя в консоли указать количество исходных путей, запросить эти пути в цикле и потом запросить целевой путь
2. Утилита создала файл журнала с указанием даты и времени в папке `.log` рядом с исполняемым файлом приложения
3. Утилита написала в файл журнала лог с информацией о путях
4. Утилита копирует каждый указанный файл из сходников в необходимую директорию
5. Утилита закачивает свою работу и пишет в журнал лог об успехе


## какие ситуации логируются

1. Если не переданы аргументы debug
2. Если не обнаружен файл с настройками debug
3. При копировании каждого файла : info - файл скопирован, error - файл не скопирован, но копирование не прерываем
4. Если целевой директории не было, но записываем лог info о создании директории и создаем директорию
5. При неожиданном исключении записываем error лог и прерываем программу
